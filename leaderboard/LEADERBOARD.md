## Add your skill to the list

Any public GitHub repo with a `SKILL.md` file at the default branch will be included in the next weekly scan. To improve your grade:

```bash

aif fix SKILL.md --write    # autofix deterministic issues
aif score SKILL.md          # check your grade
```
